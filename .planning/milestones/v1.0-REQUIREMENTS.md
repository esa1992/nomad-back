# Requirements: Nomad Games

**Defined:** 2026-09-05
**Core Value:** Короткая, честная и приятная на ощупь партия в Альчики: физика броска ощущается «настоящей», результат матча нельзя подделать с клиента, сессия занимает 2–5 минут.

Locked product facts: guest-first then username/password bind; EN+RU; catalog Alchiki + Stick Pull + Coming Soon; bots / private / quick / ranked; cosmetics without real IAP; static how-to; colorful nomadic art; server is source of truth.

Technical prescriptions (research): Flutter 3.47 + Flame + Forge2D (2.5D / 2D physics); Java 21 + Spring Boot modular monolith; dyn4j on server; PostgreSQL; no Redis on day one; Glicko-2; input → server sim → keyframe replay.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Physics Prototype Gate

- [x] **PROTO-01**: On a mid-range Android device the player can aim, hold-to-throw, and knock target bones with readable mass, collisions, rotation, friction, and restitution at about 60 FPS
- [x] **PROTO-02**: The same throw input can be simulated by a headless JVM dyn4j harness that emits a closed keyframe buffer the Flutter client can interpolate (no client-authored score)

### Authentication

- [x] **AUTH-01**: Player can start as a guest and reach a first match without creating a username
- [x] **AUTH-02**: Player can bind a unique username and password to the same guest identity later, keeping progress, cosmetics, and wallets (no second account, no summed balances)
- [x] **AUTH-03**: Bound player can log in on a new session with username/password and stay signed in across app restarts via rotating refresh tokens
- [x] **AUTH-04**: Player can log out; guest device identity remains until bind or reinstall

### Catalog

- [x] **CAT-01**: Player can open a game catalog showing Alchiki as playable
- [x] **CAT-02**: Player can open Stick Pull as playable from the same catalog
- [x] **CAT-03**: Player can see future games as Coming Soon tiles (not fake playable entries)

### Alchiki

- [x] **ALCH-01**: Player can complete a turn by choosing throw direction, holding to set power, and releasing to throw the saka
- [x] **ALCH-02**: After physics settle, the throwing player scores 1 for each target bone fully outside the circle; those bones are removed
- [x] **ALCH-03**: A match uses 5–7 target bones, first to 5 points or highest score after 8 turns each / 4:00, with a hard cap of 5:00
- [x] **ALCH-04**: Player can open skippable static how-to cards (EN+RU) before the first Alchiki match and reopen them from pause
- [x] **ALCH-05**: Saka leaving the circle scores 0 and returns for the owner's next throw; scoring happens only after bodies sleep (or ~1.2s settle timeout)

### Stick Pull

- [x] **STICK-01**: After a server 3-2-1-GO countdown, two players tap to pull a shared stick; the marker moves in real time
- [x] **STICK-02**: Stamina reduces force when the player mashes; rhythm/recovery is required to win, not peak tap rate alone
- [x] **STICK-03**: A match lasts about 15–40 seconds and ends when the marker crosses a win threshold or the clock hits 0
- [x] **STICK-04**: Online taps are accepted by the server at most 10 per second; extra taps grant no force; regularity is logged as suspect, not auto-banned in v1
- [x] **STICK-05**: Player can open skippable static how-to cards (EN+RU) for Stick Pull

### Bots

- [x] **BOT-01**: Player can play Alchiki against EASY, NORMAL, and HARD bots that make visible mistakes (no ML)
- [x] **BOT-02**: Player can play Stick Pull against EASY, NORMAL, and HARD bots with human-like tap jitter
- [x] **BOT-03**: A new player can beat Alchiki EASY in under 3 minutes using the static how-to

### Match Modes

- [x] **MODE-01**: Player can create a private room and get a short 4–6 character join code
- [x] **MODE-02**: Another player can join that room by entering the code
- [x] **MODE-03**: Player can start Casual Quick Match and be paired with a random opponent, or be offered bot / invite if the queue is empty (no 60s fail spinner)
- [x] **MODE-04**: Bound player can start a Ranked match that updates Glicko-2 rating (cosmetics ignored; no bot opponent)
- [x] **MODE-05**: After bot, private, and casual matches the player can accept Rematch within a short window

### Session Authority

- [x] **SESS-01**: Match result, pocketed bones, Stick Pull winner, coins, rating, and grants are decided only on the server; the client cannot submit a score
- [x] **SESS-02**: After a brief disconnect in Casual Alchiki the player can rejoin within 30 seconds and resume from a full server snapshot
- [x] **SESS-03**: Ranked disconnect uses a shorter window (~15–20s), an aggregate pause budget, and a rated forfeit if the player does not return
- [x] **SESS-04**: Stick Pull online uses a short reconnect window (~8s casual / ~12s ranked) and then forfeits; no bot-fill mid-tug
- [x] **SESS-05**: Consented leave/forfeit ends the match immediately (loss; rated loss if Ranked)

### Profile

- [x] **PROF-01**: Player can view a profile with username (or Guest), avatar, level, XP, matches, wins, losses, win rate, rating, best rating, and selected cosmetics
- [x] **PROF-02**: Player can view per-game statistics for Alchiki and Stick Pull
- [x] **PROF-03**: Player can choose an avatar from a small original preset set (no arbitrary photo upload in v1)

### Leaderboard

- [x] **LEAD-01**: Bound player can view a global leaderboard filtered by game
- [x] **LEAD-02**: Player can switch the board between current season and all-time
- [x] **LEAD-03**: Seasons apply a soft rating reset; boards never rank by coin balance; guests are excluded

### Economy

- [x] **ECON-01**: Player receives COINS (and occasional GEMS) from match rewards decided on the server
- [x] **ECON-02**: Player can browse a cosmetic shop (saka colors/materials/ornaments, trail, effects, victory animation, Stick Pull skins) and buy with COINS/GEMS
- [x] **ECON-03**: Player can equip owned cosmetics from inventory; equipped items never change physics, tap power, or aim assist
- [x] **ECON-04**: Wallet balances come only from a server ledger; client-displayed numbers cannot grant items
- [x] **ECON-05**: Purchase records are idempotent (same client request cannot double-spend); an empty unique-token purchase table exists so later IAP can attach without a rewrite

### Presentation

- [x] **PRES-01**: All player-facing strings are i18n keys; EN and RU ship complete
- [x] **PRES-02**: Catalog, matches, and shop use a colorful traditional nomadic/Asian visual style with original themes only (Gold / Neon / Ice / Fire / Space / original ornaments)

### Analytics

- [x] **ANLT-01**: Backend logs APP_STARTED, REGISTERED, LOGIN, MATCHMAKING_STARTED, MATCH_FOUND, MATCH_STARTED, MATCH_FINISHED, MATCH_ABANDONED, ITEM_PURCHASED without a separate analytics SaaS

- **SOCL-02**: Friends list, clubs, free-text or voice chat
- **SOCL-03**: Tournaments / brackets
- **GAME-01**: A third traditional game beyond Coming Soon
- **ALCH-06**: Alshy-face scoring mode and 15-bone sport rules
- **STICK-06**: Same-device two-thumb couch tug

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Real-money IAP in v1 | Owner deferred; shop runs on earned COINS/GEMS |
| Pay-to-Win stats on saka/stick | Destroys Ranked trust and core value |
| Coin-wager / buy-in tables | Bankroll anxiety; not this product |
| Microservices / Kubernetes | One developer; modular monolith |
| Redis as source of truth | Postgres owns wallets and outcomes; Redis only later for queues |
| ML bots | Scripted EASY/NORMAL/HARD with visible mistakes |
| Dynamic animated tutorial | Owner: static cards only |
| Lockstep physics or client rest poses | Cross-device / cross-engine desync and cheat surface |
| Licensed IP / others' ornaments | Legal; original art only |
| Required email / phone / Facebook login | Guest + username/password |
| Chat, clubs, spectate, season pass, gacha, ads | Support/moderation/predation cost before the throw is proven |
| Unity or Godot as production client (unless Phase 1 gate fails) | Solvers do not run on the JVM authority; catalog shell is cheaper in Flutter |
| Commercial anti-cheat SDKs / Play Integrity in v1 | Clamp + authority + stamina are the product; kernel detectors are v2 |
