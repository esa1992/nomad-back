# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **EXTENDS** `06-UI-SPEC.md` (which extends `05` → `04` → `03` → `02` → `01`). ## Spacing Scale

Declared values (must be multiples of 4). Overlay padding and gaps use **only** this set — same as Phase 1–6:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Field label→input gap; board rank numeral inset; soft-lock toast inset |
| sm | 8px | Compact chip gap; bind form field stack gap; season/all-time segment gap; board row vertical pad |
| md | 16px | Default catalog / profile / boards / search / bind-sheet padding from screen edges; gap between sibling buttons; gap between Ranked CTA and Quick Match on a tile |
| lg | 24px | Bind sheet heading → form; boards header → filter chips; Ranked searching spinner → Cancel |
| xl | 32px | Bottom safe inset under primary CTAs (plus system safe-area); bind sheet bottom pad |
| 2xl | 48px | Minimum touch target for every button, chip, language toggle, Ranked, Quick Match, Bind, Sign in, Log out, Boards, Cancel search, Rejoin, soft-lock Bind now, field height |

## Accessibility

- Every control is a text-labeled widget with minimum **48×48 dp** hit target (`2xl`), including Ranked, Bind account, Sign in, Log out, Boards, Cancel search, Bind now, Not now, Find Ranked match, Rejoin, and text fields.
- No icon-only auth / Ranked / Boards controls.
- Password fields: TalkBack labels `passwordLabel`; errors announced as text, not color alone.
- Soft-lock and bind sheets: focus moves to heading; dismiss controls labeled.
- Boards: rank + player + rating announced per row; local row includes `you`.
- Ranked searching must not rely on animation alone — `Searching…` text always visible.
- Reconnect timers always show numeric `{ss}` — not color pulse alone.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` on `#1B6B3A`, `#F4E8C8` on `#C43C2C`.
- Disabled buttons: 40% opacity, still labeled.
- Locale switch regenerates every visible string; usernames stay as entered.
