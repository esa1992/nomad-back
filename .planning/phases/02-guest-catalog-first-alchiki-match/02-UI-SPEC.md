## Interaction Contract

| Gesture | Target | Behavior |
|---------|--------|----------|
| Tap | Play Alchiki | If `howto.alchiki.seen` is false → `/howto/alchiki` then match. If true → `/match?difficulty=` using the selected chip (default EASY). Silent guest must already exist; if mint failed, show guest error instead. |
| Tap | Easy / Normal / Hard | Selects chip. Does not navigate. |
| Tap | Coming Soon tile | No navigation, no snack, no haptic. |
| Tap | EN / RU | Overrides locale via Riverpod; persists with how-to-seen prefs (not secure storage). |
| Swipe horizontal | How-to `PageView` | Moves one card. No wrap from 5 back to 1. |
| Tap | Skip | Persist seen; go to match at selected difficulty. Available on card 1 (D-13) and later first-run cards. |
| Tap | Next | Advance one card. Hidden on card 5. |
| Tap | Play Alchiki (card 5) | Persist seen; go to match. |
| Tap | Back to match | Close how-to; return to paused match. Does not clear seen. |
| Drag | World around saka (not Hold Throw) | Rotates a **fixed-length** aim arrow. No slingshot, no drag-back, no cosmetic aim-assist grow. Player turn only. |
| Press + hold | Hold Throw | Charges 150–1100 ms. Meter fill = normalized charge. Hold past max stays at 100% (pulse opacity 80%↔100% at 4 Hz using accent). Release commits `ThrowInput` over REST. Disabled while `!game.isLoaded`, throwing, replaying, bot turn, paused, or turn clock expired. |
| Tap | Pause | Opens pause overlay; freezes player input. Server clocks keep running (server Instant is truth). |
| Tap | Resume | Closes pause; restores player input if it is still the player's turn. |
| Tap | How to play | Opens the **same** five-card route without clearing seen (D-14). |
| Tap | Leave match | Opens confirm. Stay dismisses. Leave match confirm pops to catalog and ends the bot match (client cannot submit a win). |
| Tap | Retry | Repeats the failed guest mint, catalog GET, match POST, or throw POST. |
| Tap | Back to catalog | From result or match-start error → `/`. |

Charge window: 0.15–1.1 s (150–1100 ms). Turn clock 20s to release; timeout = forfeit throw (saka stays, 0) then bot half if the match continues. Scoring only after sleep or ~1.2s settle. Saka-out = 0 and saka returns.

When local preview and server keyframes diverge, **keyframes win** (D-10 / D-24).

| Player throwing / preview | Bodies moving; rim may flash | disabled | Pause disabled | `settled` implicit; **no** `+1` yet; `preview` unchanged |
| Player settled, awaiting REST | Sleep or 1.2s | disabled | Pause disabled | `preview {n}`; `saka out · 0` if needed; `scored` still `—` |
| Player replay | JVM keyframes | disabled | Pause disabled | `scored {displayedScore()}` ; `+1` per pocketed target after settle |
| Bot turn | Animate bot aim + hold + keyframes | hidden | Pause enabled (leave allowed) | `Bot's turn` |
| Turn timeout | Saka stays | disabled | Pause enabled | timeout body; score 0 |
| Paused | Last poses frozen on client | disabled | Resume / How to play / Leave match | clocks still show server time |
| Leave confirm | Same as paused | disabled | Stay / Leave match | unchanged |
| Result | Last poses; scrim + panel | hidden | Back to catalog | Display scores; no preview |
| Throw error | Last poses | disabled | Retry + Pause | error body |

Rim flash: 200ms accent stroke when a **target** bone first satisfies `distance > circleR + bodyR`. Saka exit does not award `+1` and uses the saka-out line instead of a flash-for-score.

Bone counts on spawn: **5 EASY / 6 NORMAL / 7 HARD**. Same collider family as Phase 1 seed-1 hex.

## Accessibility

- Every control is a text-labeled widget with a minimum **48×48 dp** hit target (`2xl`).
- No icon-only Pause, Skip, language, or difficulty.
- TalkBack reads the full i18n label (`Play Alchiki`, `Hold Throw`, `How to play`, `Leave match`).
- `preview` vs `scored` are distinguished by **words**, not color (both use `#F4E8C8`).
- You vs Bot scores use the words `You` / `Bot` (or `Ты` / `Бот`), not color alone.
- Power is readable as a **fill width** on the meter, not hue alone.
- Whose turn is a **text banner**, not color alone.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` rim on `#1B6B3A`, `#F4E8C8` on `#C43C2C`.
- Disabled buttons: 40% opacity, still labeled, not removed from the tree (Hold Throw during bot turn is the one exception — **hidden**, so the player cannot activate it).
- Coming Soon tiles stay in the semantics tree as disabled / not-enabled buttons announcing `Stick Pull, Coming Soon`.
- Do not put Hold Throw in world space — Flutter overlay so hit-testing is widget-stable.
- Locale switch regenerates every visible string immediately; do not leave mixed EN/RU on one screen.
