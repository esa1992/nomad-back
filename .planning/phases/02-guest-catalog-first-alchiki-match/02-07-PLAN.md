## Phase Goal

**As a** guest, **I want to** open a localized nomadic catalog and complete a short, server-scored Alchiki match against a bot using skippable static how-to cards, **so that** I finish an honest first party without creating a username.

This plan is the catalog API + client mint slice (AUTH-01, CAT-01, CAT-03, D-16, D-17, D-25). Identity backend is 02-02. File count is accepted after the prior split (under the 15-file cap). Do not re-split this plan.

## Artifacts this phase produces

- `CatalogService`, `CatalogController`
- `CatalogIT`
- `SessionStore` (`playerId`, `refreshToken`)
- `NomadApi.mintGuest`, `NomadApi.refresh`, `NomadApi.fetchCatalog`
- `QueuedInterceptorsWrapper` on the main Dio; second Dio without interceptors for refresh
- `android:allowBackup="false"`; debug cleartext for `10.0.2.2`

Output: CatalogIT + guest_mint_test green; splash has no account-name field.
</objective>
