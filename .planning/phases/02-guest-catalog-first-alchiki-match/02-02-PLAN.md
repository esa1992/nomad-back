**As a** guest, **I want to** open a localized nomadic catalog and complete a short, server-scored Alchiki match against a bot using skippable static how-to cards, **so that** I finish an honest first party without creating a username.

This plan is the identity backend slice (AUTH-01, D-16, D-23, D-25). Catalog GET and client mint are 02-07. File count is accepted after the prior split (under the 15-file cap). Do not re-split this plan.
