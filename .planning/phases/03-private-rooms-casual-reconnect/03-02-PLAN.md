## Phase Goal

**As a** guest, **I want to** start an authoritative Alchiki match from a short room code, rematch, rejoin after a brief drop, or leave and forfeit, **so that** I can play a friend without Quick Match, Ranked, or a bot sitting in their seat.

This plan is the first user-visible slice: create a private room and see a shareable code (MODE-01). Join is 03-03.

- Catalog private CTA band + `/lobby` host chrome (Share + Copy)
- Complete 03-UI-SPEC ARB keys (EN+RU) so later slices do not fight l10n files
- `share_plus` 13.3.0
