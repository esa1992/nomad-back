## Spacing Scale

Declared values (must be multiples of 4). Overlay padding and gaps use **only** this set — same as Phase 1–5:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Stamina track inset; marker knot rim; how-to page-dot gap; avatar–stamina gap |
| sm | 8px | Compact chip gap; CTA row gap on Stick Pull tile; false-start toast inset; reconnect banner inner pad |
| md | 16px | Default catalog / how-to / match / search / lobby padding from screen edges; gap between sibling buttons; gap between Stick Pull tile and private band / Coming Soon |
| lg | 24px | How-to illustration → heading gap; countdown digit → GO; tug HUD avatar column → lane; result heading → score |
| xl | 32px | Bottom safe inset under primary tap zone / CTAs (plus system safe-area) |
| 2xl | 48px | Minimum touch target for every button, chip, language toggle, Quick Match, Play Stick Pull, Create Stick Pull room, Skip, Next, Pause, rematch, Rejoin, and the **full-width tap zone** height during live tug |
| 3xl | 64px | Catalog header block; Stick Pull / Alchiki tile felt-band minimum content height contribution; space before More games Coming Soon |

Exceptions: none. Touch targets use `2xl` (48px). Live tug **tap zone** is full content width × **min 48dp tall** (may grow to 96dp for comfort — still a multiple of 4; not a new spacing token). Match clock and stamina are time/% — not spacing. World-space stick length stays in Flame units and is **not** a spacing token.

### Reconnect / forfeit mid-tug (D-86 / D-87)

Grace **8 seconds** (SESS-04 casual). Clocks **freeze** visually for both while a seat is in grace (mirror Phase 3 freeze pattern; shorter window).

**Remaining player** sees a clear banner (not silent AI fill):

```
│ Opponent reconnecting… 8             │  Label 14 cream on wood strip
```

**Dropped player (isolate alive):** auto-retry; banner `Reconnecting… {ss}` on own client.
**Process death inside grace:** Rejoin overlay — heading `Reconnecting… {ss}`, accent **Rejoin match**, no Back to catalog on that overlay.
**Expiry:** dropped seat **forfeits**; remaining player gets **You win** (+ optional `Opponent disconnected`); dropped client later sees **Opponent wins** + Back to catalog. **Never** spawn a bot into the seat mid-tug.

## Accessibility

- Every control is a text-labeled widget with minimum **48×48 dp** hit target (`2xl`), including Quick Match, Play Stick Pull, Create Stick Pull room, Skip, Next, Pause, rematch, Rejoin, and the live tap zone (full width × ≥48 tall).
- No icon-only Stick Pull / Mash / Pull controls.
- Stamina: TalkBack announces `Stamina {n} percent` (add key `staminaA11y`) — not color alone. Exhaust flash is supplemental.
- Countdown: announce each digit and `GO`; do not rely on haptic alone.
- Marker position: optional a11y live region `Marker {percent} toward you` at low frequency (≤1 Hz) — Claude's discretion: ship if TalkBack testing needs it; visual lane remains primary.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` on `#1B6B3A`, cream marker on felt.
- Disabled / pre-GO tap zone stays labeled; false-start toast is text, not color-only.
- Locale switch regenerates every visible string; `GO` stays Latin in RU.
- Reconnect waiting must not rely on animation alone — timer text always visible.
