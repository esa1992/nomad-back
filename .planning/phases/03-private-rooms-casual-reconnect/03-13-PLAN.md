## Phase Goal

**As a** guest, **I want to** start an authoritative Alchiki match from a short room code, rematch, rejoin after a brief drop, or leave and forfeit, **so that** I can play a friend without Quick Match, Ranked, or a bot sitting in their seat.

This slice: close VERIFICATION truth 4 / CR-01 / WR-01 — isolate-alive retry actually rejoins; overlay timer follows server remaining grace.

Root cause: **plan-deficiency**. 03-10 told the executor to auto-retry with a new ws-ticket and skip Rejoin overlay, without requiring POST /rejoin. Tests never asserted NomadApi.rejoin on isolate-alive onDone. Registry add() appending sockets was unspecified.

## Artifacts this phase produces

- Isolate-alive path: POST rejoin → persist rotated token → ws-ticket → MatchSocket.connect
- One WebSocket decorator per seat; stale close does not restart grace
- GET match `reconnectSecondsLeft` (0–30) for the caller's dropped seat
- Overlay countdown seeded from that remaining grace
- `reconnect_overlay_test` isolate-alive + remaining-grace cases; `ReconnectIT` remaining grace; `MatchSessionRegistryTest`
