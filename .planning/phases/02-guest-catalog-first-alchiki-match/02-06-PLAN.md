## Phase Goal

**As a** guest, **I want to** open a localized nomadic catalog and complete a short, server-scored Alchiki match against a bot using skippable static how-to cards, **so that** I finish an honest first party without creating a username.

This plan is the last vertical slice: scripted bots + EASY default + PRES-02 polish (BOT-01, BOT-03, PRES-02, D-21, D-22, D-25). After it a guest can finish an EASY match.

## Artifacts this phase produces

- `ScriptedBot.nextThrow(difficulty, seed, tableId, remainingBoneIds) → ThrowInput`
- EASY noise: aim ±0.60 rad, hold 200–450 ms (RESEARCH A3)
- NORMAL: aim ±0.25 rad, hold 400–800 ms
- HARD: aim ±0.10 rad, hold 700–1050 ms, 15% intentional miss
- REST throw response field `botThrow` `{ input, keyframes, displayedScore, sakaOut, pocketedIds }`
- `AlchikiMatchPage.playBotTurn`
- `bot_turn_test.dart`

Purpose: Without a visible scripted bot the catalog path is not a match. The client must not invent bot scores.

Output: ScriptedBotTest + ThrowAuthorityIT bot half + bot_turn_test green. Owner UAT (human-check) confirms EASY under 3 minutes and palette.

1. Replay playerThrow.keyframes (keyframes win)
2. Set turn banner botsTurn; hide Hold Throw
3. Animate aim to botThrow.input.aimAngleRad and power meter to holdMs
4. Replay botThrow.keyframes
5. startTurn/resetSakaToRim — next player throw from (0,-1.15); pocketed stay gone
6. HUD scored/botScore from match / botThrow.displayedScore
