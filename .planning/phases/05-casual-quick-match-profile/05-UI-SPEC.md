## Spacing Scale

Declared values (must be multiples of 4). Overlay padding and gaps use **only** this set — same as Phase 1–4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Avatar chip art inset; metric row key/value gap; preset grid letter inset |
| sm | 8px | Compact chip gap; fallback button row gap; profile section gap; XP bar track inset |
| md | 16px | Default catalog / search / fallback / profile / waiting padding from screen edges; gap between sibling buttons; gap from Alchiki tile to private CTA band |
| lg | 24px | Gap between search spinner and Cancel search; profile header to metrics; rematch waiting heading to timer |
| xl | 32px | Bottom safe inset under primary CTA (plus system safe-area); profile side inset under cosmetics row |
| 2xl | 48px | Minimum touch target for every button, chip, language toggle, Quick Match, Play Alchiki, Cancel search, fallback CTAs, avatar chip, avatar preset cell, Play again, Cancel rematch |
| 3xl | 64px | Catalog header block; space between private CTA band and Coming Soon; profile avatar preferred display size (64dp circle) |

Exceptions: none. Touch targets use `2xl` (48px). Catalog **avatar chip** outer hit target is **48×48**; drawn face may be 40dp inside. Profile hero avatar is **64dp** (`3xl`) display size, not a new spacing token. Search timeout is **time**, not spacing. World-space bone / saka radii stay in meters and are **not** spacing tokens.

**Source:** 04-UI-SPEC.md Spacing Scale. Claude's discretion (yolo): 8s search band mid-point does not add a spacing exception; profile avatar 64dp uses `3xl`.

## Color

60 / 30 / 10 split is mandatory. Same hexes as Phase 1–4. One accent. One destructive semantic.

Across a session the player still spends most time on the **felt table**, so Dominant stays felt. Catalog / lobby / join / splash / how-to / shop / **search / fallback / profile / rematch-waiting** pages fill with Secondary wood. Dominant felt remains the Alchiki tile band, the table, and the shop static felt preview disk.

## Accessibility

- Every control is a text-labeled widget with a minimum **48×48 dp** hit target (`2xl`), including Quick Match, Play Alchiki, Cancel search, Play vs bot, Invite friend, Cancel rematch, avatar chip, avatar preset cells, and Save avatar.
- Avatar chip: TalkBack uses `openProfileA11y`, not “image” alone.
- No icon-only Cancel / Match / Profile.
- Soft rating: announce `Rating {n}`, Best `{best}` — not gold fill alone.
- Selected avatar preset: words + accent fill; Save avatar label remains when disabled.
- Stick Pull empty state is text (`No matches yet`), not a blank section.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` rim on `#1B6B3A`, `#F4E8C8` on `#C43C2C`.
- Disabled buttons: 40% opacity, still labeled.
- Locale switch regenerates every visible string immediately; `Guest` / `Guest-XXXX` stay Latin.
- Searching must not rely on animation alone — `Searching…` text is always visible.
