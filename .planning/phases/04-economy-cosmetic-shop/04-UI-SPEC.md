# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **EXTENDS** `03-UI-SPEC.md` (which extends `02-UI-SPEC.md` → `01-UI-SPEC.md`). Do not replace Phase 1–3 table palette, type scale, spacing scale, Hold Throw chrome, bone/saka fills, private-room chrome, rematch, or reconnect. This file adds **dual wallet chip**, **Shop** entry, `/shop` category shelf + SKU grid + Owned inventory, **static felt preview**, buy/equip CTAs, and **result-overlay reward lines**.
>
> Stack: Flutter 3.47 `MaterialApp.router` + Flame 1.38 parlor + Flutter overlay widgets + `go_router`. **Not** a shadcn/web app. Values below are Flutter logical pixels (dp). 1 dp = 1 CSS px at 1×.

## Interaction Contract

| Gesture | Target | Behavior |
|---------|--------|----------|
| Tap | Shop (catalog) | Push `/shop`. Guests allowed (D-51). Refresh wallet + catalog SKUs from server. |
| Tap | Wallet chip | No navigation. Optional: none — ignore taps (read-only). |
| Tap | Shop \| Owned segment | Switch shelf contents. Persist segment only in memory for the visit (no prefs required). |
| Tap | Category chip | Filters grid; does not purchase. |
| Tap | SKU tile | Open shop detail for that SKU. |
| Tap | Buy item | Client sends purchase with **new idempotency key**; on success refresh wallet + owned; button becomes Equip path. Retry uses a **new** key only after hard failure; double-tap same in-flight key must not double-spend (D-59). |
| Tap | Equip item | Client sends equip intent; server stores loadout; UI shows Equipped. Applies at **next match start / rematch**, not mid-throw (D-56). |
| Tap | Back to shop (detail) | Pop to `/shop` shelf; keep category + segment in memory for the visit. |
| Tap | Back to catalog (shop shelf) | Pop to `/`. Wallet chip on catalog refreshes if dirty. |
| Tap | Shop (result link) | Push `/shop` without cancelling rematch acceptance already sent; if rematch window still open on private, leaving result for shop **rejects** rematch the same as navigating away — prefer: Shop link only enabled after rematch window ends **or** treat as Back to catalog + shop. **Locked:** Shop on result **pops to catalog then pushes `/shop`**, ending the rematch window (same as Back to catalog, then shop). |
| Tap | Play again / Again? | Unchanged Phase 3; reward lines already visible; do not block on wallet animation. |
| Drag / Hold Throw | Match table | Unchanged. Cosmetics are presentation-only (D-54). |

Match create / rematch kickoff reads **server loadout** for each seat so opponents share looks (D-57). Client prefs alone never decide opponent cosmetics.

## Accessibility

- Every control is a text-labeled widget with a minimum **48×48 dp** hit target (`2xl`), including Shop, Buy item, Equip item, category chips, and Shop \| Owned segments.
- No icon-only Shop / Buy / wallet.
- TalkBack reads wallet via `walletA11y` (`{coins} COINS, {gems} GEMS`), not color alone.
- Equipped vs Buy vs price are **words**, not gold fill alone.
- Theme swatches (Neon / Fire / Space) always sit beside a text SKU name.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` rim on `#1B6B3A`, `#F4E8C8` on `#C43C2C`. Space swatch `#3D2B8E` is never used as text-on-wood without a cream label beside it.
- Disabled Buy: 40% opacity, still labeled.
- Locale switch regenerates every visible string immediately; `COINS` / `GEMS` Latin in EN; RU words as keyed.
- Insufficient-funds text stays associated with the Buy control for TalkBack.
