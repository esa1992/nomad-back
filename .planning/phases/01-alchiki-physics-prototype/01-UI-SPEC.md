## Spacing Scale

Declared values (must be multiples of 4). Overlay padding and gaps use **only** this set:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Power-meter inner inset, HUD key/value gap |
| sm | 8px | Compact HUD line gap; power-meter track height |
| md | 16px | Default overlay padding from screen edges; gap between Reset Table and Replay Throw |
| lg | 24px | Gap between power meter and Hold Throw |
| xl | 32px | Bottom safe inset under Hold Throw (plus system safe-area) |
| 2xl | 48px | Minimum touch target for Hold Throw / Reset Table / Replay Throw |
| 3xl | 64px | Reserved; do not use on this single-screen sandbox |

Exceptions: none. Touch targets use `2xl` (48px), which is already on the scale. World-space bone radii stay in meters (see 01-RESEARCH.md `TableConstants`) and are **not** spacing tokens.

**Source:** orchestrator 4px Flutter overlay grid; default GSD scale. Claude's discretion: 48px targets (not 44).

## Color

60 / 30 / 10 split is mandatory. One accent. One destructive semantic.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1B6B3A` | Felt circle fill — the parlor surface the player stares at |
| Secondary (30%) | `#241810` | Table surround outside the felt; HUD panel fill (88% opacity); Reset Table fill; power-meter track |
| Accent (10%) | `#F0B429` | **Only** the reserved list below |
| Destructive | `#C43C2C` | Error-state heading underline / error banner border. Not used on Reset Table. |
| On-dark text | `#F4E8C8` | Labels and body on secondary panels and buttons |
| On-accent text | `#241810` | Label on Hold Throw and Replay Throw |
| Saka fill | `#FFF6D6` | Shooter disk — brighter than bones, **not** the accent |
| Saka stripe | `#8B4513` | One brown diameter mark so spin reads |
| Bone fill | `#D4A574` | Six target disks |
| Bone mark | `#6B4423` | Short tick so rotation is visible |
| Rim idle | `#E8D4A8` | Circle stroke at rest (contrast on green felt) |
| Aim arrow | `#F4E8C8` | Fixed-length world-space arrow; does **not** use accent |
| Preview numeral | `#F4E8C8` | Local settle count — always prefixed with the word `preview` |
| Scored numeral | `#F4E8C8` | Authority count — always prefixed with the word `scored` |

Accent reserved for:

1. **Hold Throw** button fill (idle-enabled, pressed, and hold-at-max pulse — same hex, brightness only)
2. **Replay Throw** button fill when enabled
3. **Circle rim flash** for 200ms when a target bone becomes fully outside the circle
4. **Power-meter fill** while charging (companion of Hold Throw)

Never paint Reset Table, aim arrow, saka, bones, HUD chrome, or `+1` with `#F0B429`.

**Source:** 01-CONTEXT.md D-07 (felt, contrasting rim, bright saka); locked product direction (colorful nomadic subset); orchestrator accent lock (Hold / Replay / rim flash). Claude's discretion: hex values, saka/bone fills, destructive for errors only.

## Copywriting Contract

All Phase 1 strings are hardcoded English (D-02: no i18n screens). Verb + noun on every button.

| Element | Copy |
|---------|------|
| Primary CTA | Hold Throw |
| Secondary action | Reset Table |
| Authority action | Replay Throw |
| Empty state heading | Table reset |
| Empty state body | Drag around the saka to aim, then press Hold Throw. |
| Error state (no JVM file) | Replay is not ready. Import a JVM ThrowResolved that matches this throw, or open the golden replay. |
| Error state (input mismatch) | This replay does not match the last throw. Load a matching ThrowResolved or throw again. |
| Error state (invalid JSON) | Replay file is unreadable. Use a harness ThrowResolved with schemaVersion 1. |
| Destructive confirmation | none — this phase has no destructive action |
| Preview HUD | `preview {n}` |
| Scored HUD | `scored {n}` or `scored —` when no `ThrowResolved` is loaded |
| Saka-out line | `saka out · 0` |
| Floating score | `+1` (one popup per pocketed target, **after settle only**) |
| Debug HUD | `fps {n}` / `bodies {n}` / `settled yes` or `settled no` |

**Forbidden labels:** Submit, OK, Click Here, Cancel, Save, Reset (bare), Hold (bare), Replay (bare), No data found, Something went wrong.

**Scored vs preview (PROTO-02):** `preview` may update from local Forge2D settle. `scored` updates **only** after Replay starts (or golden load) and **only** from `ThrowResolved.pocketedCount`. Never copy a Dart rest-pose count into `scored`.

**Source:** 01-CONTEXT.md D-01, D-04, D-08, D-10; 01-RESEARCH.md Pitfall 8. Claude's discretion: exact sentences.

## Layout and Visual Hierarchy

**Focal point (primary visual anchor):** the felt circle and the bright saka on the rim. The eye must land on the table first, not the HUD.

**Hierarchy (draw order / attention):**

1. Felt circle + six bones + saka (world)
2. Aim arrow while idle / aiming (world)
3. Hold Throw + power meter (overlay, bottom center)
4. `preview` / `scored` / saka-out (overlay, top center)
5. Reset Table + Replay Throw (overlay, bottom row above Hold Throw — visible after first settle or when Replay can run)
6. Debug HUD (overlay, top leading) — lowest visual priority, 14px Label, cream on 88% secondary panel

**Camera:** 2.5D presentation only. Render-layer `scale.y = 0.86`. Do not squash Forge2D colliders. Physics stay circular.

**Overlay map (SafeArea + 16px md inset):**

```
┌──────────────────────────────────────┐
│ [fps][bodies][settled]     debug HUD │  top leading, secondary panel
│         preview 0                    │  top center
│         scored —                     │
│                                      │
│           FELT CIRCLE                │  GameWidget full bleed
│              bones / saka            │
│                                      │
│    [Reset Table]  [Replay Throw]     │  hidden until settled once
│         [power meter]                │  visible while charging
│          [ Hold Throw ]              │  always when input allowed
└──────────────────────────────────────┘
```

Hold Throw: min 48×48, preferred height 48, horizontal padding 32, width at least 192 (layout, not a spacing-token). Centered.

Reset Table / Replay Throw: min 48×48 each, 16px gap, same row, centered as a pair.

## Interaction Contract

| Gesture | Target | Behavior |
|---------|--------|----------|
| Drag | World around saka (not the Hold button) | Rotates a **fixed-length** aim arrow. No slingshot, no drag-back, no cosmetic aim-assist grow. |
| Press + hold | Hold Throw | Charges 150–1100 ms. Meter fill = normalized charge. Hold past max stays at 100% (pulse opacity 80%↔100% at 4 Hz using accent). Release commits `ThrowInput` and throws. |
| Tap | Reset Table | Instant snap of six bones + saka to spawn. Wake bodies. Clear `preview`, set `scored —`, hide floating `+1`, cancel Replay pointer. No confirm dialog. No reset animation. |
| Tap | Replay Throw | Starts only if a JVM `ThrowResolved` exists and `input` matches the last committed `ThrowInput` (or the baked golden). Interpolates keyframes. If local preview diverges, **keyframes win**. Sets `scored` from file `pocketedCount`. |

Charge window: 0.15–1.1 s (150–1100 ms). Disabled while throwing, while replaying, and until Reset Table after a committed throw has settled (next throw requires Reset Table — sandbox, not a match).

## State Matrix

| State | Table | Hold Throw | Power meter | Reset Table | Replay Throw | HUD |
|-------|-------|------------|-------------|-------------|--------------|-----|
| Empty after reset | Hex cluster of 6 bones + saka at rim; empty-state heading+body shown 2s then fade | enabled | hidden | disabled | enabled only if golden (or imported) file is already matched; else disabled | `preview 0` · `scored —` · `settled yes` |
| Aiming | Arrow visible | enabled | hidden | disabled | same as idle | unchanged |
| Charging | Arrow frozen at press angle | pressed (accent) | visible, filling | disabled | disabled | last `holdMs` may appear as debug value |
| Throwing | Bodies moving; rim may flash on exits | disabled | hidden | disabled | disabled | `settled no`; **no** `+1`; `preview` unchanged |
| Settled | Sleep or 1.2s freeze | disabled until Reset Table | hidden | enabled | enabled if JVM file matches; else disabled + error body | `settled yes`; floating `+1` per pocketed target; `preview {n}`; `saka out · 0` if saka left; `scored` still `—` until Replay |
| Replaying | JVM keyframe interpolation | disabled | hidden | disabled until replay ends | disabled (active) | `scored {ThrowResolved.pocketedCount}` |
| Replay error | Last poses remain | per settled rules | hidden | enabled | disabled | error heading + body (solution path above) |

Rim flash: 200ms accent stroke when a **target** bone first satisfies `distance > circleR + bodyR`. Saka exit does not award `+1` and uses the saka-out line instead of a flash-for-score.

## Accessibility

- Hold Throw, Reset Table, Replay Throw: minimum **48×48 dp** hit targets (`2xl`).
- No icon-only controls. TalkBack reads the full button label.
- `preview` vs `scored` are distinguished by **words**, not color (both use `#F4E8C8`).
- Power is readable as a **fill width** on the meter, not hue alone.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` rim on `#1B6B3A`.
- Disabled buttons: 40% opacity, still labeled, not removed from the tree.
- Do not put Hold Throw in world space — Flutter overlay so hit-testing is widget-stable (01-RESEARCH.md Pattern 1 / D-04).
