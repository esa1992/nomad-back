## Spacing Scale

Declared values (must be multiples of 4). Overlay padding and gaps use **only** this set — same as Phase 1–2:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Power-meter inner inset, HUD key/value gap, room-code letter-spacing |
| sm | 8px | Compact HUD line gap; chip gap; join-error inset; Guest-XXXX row gap |
| md | 16px | Default overlay / catalog / lobby / join padding from screen edges; gap between sibling buttons; gap from Alchiki tile to private CTA band |
| lg | 24px | Gap between power meter and Hold Throw; lobby code block to Share/Copy row; rematch heading to timer |
| xl | 32px | Bottom safe inset under primary CTA (plus system safe-area); lobby code top inset |
| 2xl | 48px | Minimum touch target for every button, chip, language toggle, and the join code field |
| 3xl | 64px | Catalog header block; space between private CTA band and Coming Soon tiles |

Exceptions: none. Touch targets use `2xl` (48px). Room code glyph size is Display 28 (type), not a spacing token. World-space bone / saka radii stay in meters and are **not** spacing tokens.

## Typography

Exactly four sizes and two weights. No other `fontSize` / `FontWeight` on catalog, lobby, join, overlays, or Flame HUD text.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 14px | 600 | 1.2 | Button labels, chips, HUD keys, language toggle, Guest-XXXX ready flags, reconnect banner, rematch timer, `Copied` flash, page index |
| Body | 16px | 400 | 1.5 | Lobby / join helper body, empty/error body, HUD values, saka-out line, confirm dialog body, share-sheet is OS-owned |
| Heading | 20px | 600 | 1.2 | Screen titles (`Nomad Games`, `Private room`, `Join by code`, pause / result / rematch / rejoin headings) |
| Display | 28px | 600 | 1.2 | Floating `+1`; result score pair; **room code** (lobby display + join field text) |

Weights allowed: **400** and **600** only. Do not use 500, 700, or italic for UI chrome.

### Opponent wait pose (D-35) then theatrical throw (D-34)

While the opponent has not released:

- Table **frozen** at last settle (no 60 Hz live physics)
- HUD shows **their** 20s clock (`turn {ss}`) and `Opponent's turn`
- Opponent saka stays in its parked rim slot
- Draw the **static aiming marker** (8×8 cream disk, 40% opacity, 16px above that saka). No arrow, no rotation, no WS angle
- Do **not** show Hold Throw or a live power meter

When `ThrowResolved` arrives: hide the marker; play the same theatrical aim-rotate + hold-meter + keyframe settle as the Phase 2 bot turn. Your own throw still does local Forge2D preview then morph onto JVM keyframes (D-36). Opponent clients never preview a remote throw locally.

### Reconnect banner (D-41)

Wood panel 88% opacity, cream Label 14, full content width under the turn banner. Server timer is truth (`Reconnecting… {ss}`). Clocks **do not tick** on screen while the dropped seat is in grace — show the last remaining `turn` / `match` values frozen.
No accent. No bot-fill copy (D-42).
Consented leave never shows this banner (0s grace).

If the local isolate is still alive, auto-retry is silent — keep the table, show the banner on the **opponent's** client. After process death inside 30s: replace the table with the **Rejoin overlay** (scrim + wood panel): heading `Reconnecting… {ss}`, body none, single accent **Rejoin match**. Do **not** put Back to catalog on this overlay (that path is Pause → Leave match confirm). Timer expiry without rejoin: remaining player sees result **You win**; the dropped client, if opened later, sees **Opponent wins** + Back to catalog — no Rejoin.

## Accessibility

- Every control is a text-labeled widget with a minimum **48×48 dp** hit target (`2xl`), including Share, Copy, Ready, Create room, Join by code, Join room, Play again, Again?, Rejoin, and the join field.
- No icon-only Share / Copy / Ready / Pause.
- TalkBack reads the full i18n label (`Create room`, `Join by code`, `Share code`, `Copy code`, `Ready`, `Rejoin match`).
- Room code is announced as text (`K7M4Q`), not as a decoration.
- `preview` vs `scored` stay word-prefixed, not color-only.
- You vs opponent scores use the words `You` / `Guest-XXXX` (or `Ты` / `Guest-XXXX`), not cream vs ice alone.
- Whose turn is a **text banner** (`Your turn` / `Opponent's turn`), not saka color alone.
- Reconnect state is a **text banner + numeric timer**, not color alone.
- Two sakas are distinguishable by fill **and** by HUD words; ice `#7EB6D9` is never the only cue that it is the opponent's turn.
- Contrast: `#F4E8C8` on `#241810`, `#241810` on `#F0B429`, `#E8D4A8` rim on `#1B6B3A`, `#F4E8C8` on `#C43C2C`, `#FFF6D6` and `#7EB6D9` on `#1B6B3A`.
- Disabled buttons: 40% opacity, still labeled. Hold Throw during opponent turn / grace remains **hidden**.
- Locale switch regenerates every visible string immediately; `Guest-XXXX` stays Latin.
- Join errors must remain associated with the text field for TalkBack (helper / error text under the field).
