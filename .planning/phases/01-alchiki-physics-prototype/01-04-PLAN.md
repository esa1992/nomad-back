## Phase Goal

**As a** player on a mid-range Android device, **I want to** aim, hold-to-throw, and knock bones with readable physics, **so that** the same throw is scored only from a JVM keyframe buffer.

Vertical slice: the authority write — a ThrowInput file becomes a ThrowResolved file whose pocketedCount comes only from dyn4j (PROTO-02). Runs in parallel with 01-03 (no client Dart file overlap; this plan does not invent a client hex layout).

- Java DTOs: ThrowInput, TableConstants, Keyframe, ThrowResolved
- Dyn4jBurstSim + HarnessMain CLI
- BurstSimTest green
- `client/assets/replays/golden_input.json` BurstSimTest fixture written before the CLI run
- `client/assets/replays/golden_throw.json` generated by the CLI
