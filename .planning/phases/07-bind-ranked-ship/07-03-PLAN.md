<interfaces>
POST /v1/identity/login (permitAll):
Body: {
  "username": string,
  "password": string,
  "guestPlayerId": UUID | null,
  "adopt": "none" | "import" | "drop"   // default "none"
}
Success 200: TokenPair for bound player (guest=false claims).

Adopt contract (D-93) — server is source of truth; never sum/max wallets, cosmetics, XP, SoftElo, or Glicko:
- adopt=none (default): issue bound tokens only; do not mutate guest or bound wallets.
- adopt=import: allowed ONLY if bound target has matches==0 AND ledger spend==0; then copy guest wallets/cosmetics onto bound once and revoke guest refresh tokens / abandon guest device row. Otherwise 409 import_not_eligible (UI must offer drop).
- adopt=drop: revoke all refresh tokens for guestPlayerId; leave bound wallets/cosmetics/XP/ratings unchanged; never copy guest balances onto bound.

Response MAY include adoptHint: NONE | IMPORT_ELIGIBLE | DROP_REQUIRED when guestPlayerId supplied and adopt=none, so Flutter can choose sheet (implemented in 07-10).

POST /v1/identity/logout (authenticated): revoke all refresh rows for playerId.
TokenService.rotate: load PlayerEntity by refresh playerId; issue(playerId, player.isGuest()).

Client mint-new-guest after logout is UI (07-10); this plan greens logoutMintsGuest by simulating revoke + guest mint in IT.
</interfaces>
