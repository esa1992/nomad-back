# Roadmap: Nomad Games

## Overview

Nomad Games ships as a catalog parlor platform, not a single asyk title. Phase 1 is a hard physics gate: if the Alchiki throw does not feel like skill on a mid-range Android device, and the same input cannot be scored by a headless JVM dyn4j keyframe harness, the stack is reopened before any identity or shop exists. After the gate, a guest can reach a first honest Alchiki bot match from the catalog, then play a friend by room code with casual reconnect, earn cosmetic currency, tap Casual Quick Match, and open Stick Pull as a second live title. Ranked, Glicko-2, and skill leaderboards stay in v1 but only after that casual loop is stable. GitHub Actions and compose harden fold into the last phase — they are not a standalone DevOps bucket.

### Phase 2: Guest Catalog + First Alchiki Match

  1. Player can start as a guest (no username) and reach a first Alchiki match from a catalog that shows Alchiki as playable and future games as Coming Soon

### Phase 7: Bind, Ranked + Ship

**Goal:** As a guest player, I want to bind progress under a username, play honest Ranked with skill boards, and ship behind CI, so that identity survives devices and ratings stay fair without P2W
**Mode:** mvp
**Depends on:** Phase 6
**Requirements:** AUTH-02, AUTH-03, AUTH-04, MODE-04, SESS-03, LEAD-01, LEAD-02, LEAD-03, ANLT-01
**Success Criteria** (what must be TRUE):

  1. Player can bind a unique username and password to the same guest identity (progress, cosmetics, and wallets kept; no second account; no summed balances), log in on a new session, stay signed in across restarts, and log out while the guest device identity remains until bind or reinstall
  2. Bound player can start a Ranked match that updates Glicko-2 (cosmetics ignored, no bot opponent); a ranked disconnect uses a shorter window (~15–20s) plus pause budget and becomes a rated forfeit if they do not return
